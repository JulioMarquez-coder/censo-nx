# Census Data Visualization Web Application

Census Data Visualization Web Application is an Angular/Nx project created to present and visualize census population data for different states. The project also includes a Puerto Rico map visualization to display population information by municipality in a more interactive and visual way.

## Live Demo

https://censo-nx.vercel.app

## Repository

https://github.com/JulioMarquez-coder/censo-nx

## Technologies Used

- Angular
- Nx
- TypeScript
- HTML
- CSS
- Tailwind CSS
- GitHub
- Vercel

## Features

- Displays census population data in a web application
- Organizes population information by state
- Includes a Puerto Rico map visualization
- Allows users to view Puerto Rico population data by municipality
- Uses Angular components for the front-end structure
- Uses Tailwind CSS and CSS for styling and layout design
- Uses Nx to manage the project workspace
- Deployed online using Vercel
